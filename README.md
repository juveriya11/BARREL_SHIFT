# Barrel Shifter – Verilog

## Project Overview

This project implements a parameterized barrel shifter using Verilog HDL. A barrel shifter is a combinational digital circuit capable of shifting or rotating a binary data word by a specified number of positions in a single operation.

## Features

- Designed using Verilog HDL
- Combinational logic implementation
- Supports selectable shift operations
- Includes a Verilog testbench
- Simulated using ModelSim
- Suitable for digital electronics and RTL design studies

## Project Files

- `barrel.v` – RTL design of the barrel shifter
- `barrel_tb.v` – Testbench used to verify the design
- `.bak` files – Local backup files generated during development

## Tools Used

- Verilog HDL
- ModelSim
- RTL Simulation

## Simulation

The design was tested using a Verilog testbench in ModelSim. The testbench applies different input data and shift values to verify the functionality of the barrel shifter.

## Applications

Barrel shifters are commonly used in:

- ALUs
- Microprocessors
- Digital signal processing
- Data manipulation units
- Computer architecture
